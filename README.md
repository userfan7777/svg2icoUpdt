svg2icoUpdt is an extension to inkscape to export directly to .ico files
How to install?
Copy the "svg2ico" .inx and .py files and place them onto the user extensions folder
How to use?
Once you got your design and want to extract it just click on "File" and then "Save to...", on the save window on the bar that has the file you want to extract it, select "Windows Icon (.ico)"
